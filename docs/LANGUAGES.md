## Documentation layers

| File | Role | Language |
| --- | --- | --- |
| [README.md](../README.md) | Canonical, complete documentation: requirements, installation, settings, architecture, troubleshooting | English |
| [docs/README.en.md](README.en.md) | Short English introduction, same structure as the translated pages | English |

The language pages are **short introductions, not word-for-word translations of the full README**. They share the same structure and the same version. Installation details, configuration reference, architecture, and troubleshooting live in the English README.
