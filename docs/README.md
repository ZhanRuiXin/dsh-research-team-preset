## What the mode is

Research Team Mode is a DSH agent preset for running end-to-end research as a small team. A Lead plans the work and keeps the task board; six default specialists cover advisory review, literature and evidence, code, runs, independent review, and paper writing.

The mode is for substantive research that needs traceable evidence and clear role boundaries. It is not a one-shot Q&A mode.
